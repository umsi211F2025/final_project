# Final Project Instructions

## Overview

You are free to create any project you want. It could be an extension of something you did for a previous problem set. Or it could be something completely different.

You will be expected to make progress every week, including pushing an updated version of your code and related files to GitHub each week. You will also be asked to make a mini-presentation each week during class and to comment on other students' presentations.

## Requirements

There are not uniform requirements, since projects may be of very different kinds. But your work log should reflect steady progress, with about 10 hours of work each week.


## Deliverables
- **Work Log:** Keep a clear, timestamped log of each work session in your `work-log.md` file.
- **Copilot Usage and Self-reflections:** In your `reflections.md` file this week, include an entry for each task or debugging session, and reflect on the process of describing the task or issue and having the copilot solve it. If you discovered any particularly effective prompts, include them. Also include any self-reflections at the end of the file, as with previous `reflections.md` files.
- **Spec File:** A `spec.md` file that describes what the copilot is supposed to implement for your project. You will develop this spec in pieces, and you will feed it to the copilot in chunks as you work on your project.
- **Presentation files:** Any slides or other files you use for your weekly presentations. The repo include a `presentations/` directory for this purpose, with a template document for the first presentation.
- **Video demo:** A short (2-5 minute) video demo of your project, showing how it works and what it does. Host it on YouTube or similar. Ask if you'd like to have a private place to share the video rather than putting it on a public site.
- **README.md:** Explains what the user/instructor should do to get things running. It should also include a link to the video demo. 

## Submission Checklist
- [ ] `README.md`, including link to video demo
- [ ] `work-log.md` file
- [ ] `reflections.md` file
- [ ] `spec.md` file
- [ ] Presentation files in `presentations/` directory
- [ ] Regular commit history
- [ ] Push your repo back to GitHub
- [ ] Submit on Canvas with a note saying that it's ready for grading
